PYTHON BRIDGE PRACTICE FILES

Keep these text files in the same folder as your Python program.

names.txt   - one student name per line
scores.txt  - one integer score per line
sensor.txt  - one decimal temperature per line
clubs.txt   - club name and remaining capacity, separated by a comma
rooms.txt   - four room-use values per day, separated by commas
tournament_scores.txt - 20 tournament scores: four scores for each of the five names
stock_as.txt - five stock records stored as four lines per record
touch_grid.txt - a 6 by 11 touchscreen test grid
student_project.txt - pseudocode source used by Advanced Challenge 3

Do not open a data file in WRITE mode unless the task tells you to replace it.
