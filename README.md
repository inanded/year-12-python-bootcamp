# Year 12 Python Bootcamp

A self-contained learning site that helps Year 12 students translate secure Cambridge-style pseudocode knowledge into Python.

The site includes scaffolded activities, keyword support, increasingly independent challenges, progress tracking, downloadable practice files, and save/restore reports.

## Run locally

```bash
pnpm install
pnpm dev
```

## Publish

Pushes to the `main` branch are built and published automatically through GitHub Pages.
